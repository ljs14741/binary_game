말달리자 경마내기게임

말 하나 골라놓고 결승선까지 조마조마. 커피내기·점심내기·벌칙뽑기에 딱!

🏇 말달리자

▲ 꼴찌로 들어온 말의 주인이 벌칙!

🏁 최종 순위

    방법

    1. 참가자 이름을 쉼표 또는 줄바꿈으로 구분해 입력 (2~30명)
    2. 꼴찌 벌칙 뽑기(기본) / 1등 우승 뽑기 중 선택 후 경주 시작!
    3. 시작 시 말마다 등급 랜덤: 🏇 일반 94% / 🦄 레어 5% (속도 +10%, 부스터 확률 1.5배) / 🐉 에픽 1% (속도 +20%)
    4. 🥕 당근 = 부스터(잠시 2배 속도, 1등은 못 씀) · 돌멩이 = 빙글 돌며 뒤로 밀리고 한동안 느려짐 · 💧 웅덩이 = 잠시 느려짐. 마지막(또는 첫 번째)으로 결승선을 넘는 말의 주인이 벌칙(또는 우승)

    특징

    • 커피내기·점심내기·벌칙뽑기·당번뽑기용 경마내기게임 (사다리·룰렛 대신)
    • 역전 요소 – 꼴찌 부스터, 막판 스퍼트, 1~3위만 걸리는 선두 억까
    • 말마다 고유 색상으로 순위 한눈에 구분, 최대 30명 참가
