핀볼룰렛 랜덤공뽑기

공 하나가 끝까지 어디로 떨어질지 모릅니다. 커피내기·점심내기·벌칙뽑기에 딱!

🎱 참가자 입력

🏆 1등
축하드립니다~!
🏁 최종 순위

    게임 방법

    1. 참가자 이름을 한 줄에 한 명씩(또는 쉼표로 구분해) 입력합니다. (2~30명)
    2. 게임 시작을 누르면 경주가 시작됩니다.
    3. 가장 먼저 도착한 사람이 1등으로 자동 기록되고, 순위판에 표시됩니다.
    4. 다시하기로 재경기, 공유 버튼으로 링크를 친구들과 나눠보세요.

    핵심 특징

    • 랜덤공뽑기·핀볼뽑기·랜덤볼뽑기 — 공이 떨어지는 핀볼룰렛으로 공정 추첨
    • 커피내기·점심내기·벌칙뽑기·당번뽑기에 딱 — 사다리타기·룰렛 대신
    • 한 번에 결과 확인, 재경기로 빠르게 여러 판 진행
    • 모바일·PC 모두 부드럽게 동작, BGM·전체화면·볼륨 조절 지원

    안내

    매번 실행할 때마다 결과가 달라질 수 있어요. 특정 사람이 유리해지지 않도록 기본 동작을 설계했습니다.
    또한 3초 동안 공이 움직이지 않으면 맵 최상단에서 자동으로 다시 시작해요. 화면 밖으로 벗어나도 자동 복귀합니다. 소리를 켜고 즐기면 더 몰입감 있어요!
