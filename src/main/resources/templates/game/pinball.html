🎲 핀볼 랜덤 뽑기

게임 방법

  1. 참가 인원(최대 30명)과 닉네임을 입력합니다.
  2. 시작 버튼을 누르면 공이 발사되고 핀볼 맵을 통과합니다.
  3. 가장 먼저 골인한 참여자가 1등으로 자동 기록됩니다.
  4. 1등으로 걸린 사람이 커피 쏘기 ㅎ_ㅎ
  5. 사운드 키고 하세요~

핵심 특징

  • 완전 랜덤 추첨: 물리 엔진 기반 경주형 랜덤 뽑기
  • 룰렛/사다리 대체로 모임 벌칙/자리배치/팀나누기 활용
  • 핸드폰에서도 부드럽게 동작
  • 버그 많아서 계속 수정중

공정성 안내

결과는 서버 저장 없이 클라이언트에서 실시간 물리 시뮬레이션으로만 결정됩니다. 반복 실행 시 매번 다른 결과가 나올 수 있으며, 조작이 불가능하도록 동일 조건에서 확률적으로 공정한 결과가 나오도록 설계했습니다.
